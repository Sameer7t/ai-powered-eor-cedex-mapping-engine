# Local data files

This directory is intentionally excluded from the public repository because it can contain proprietary CEDEX references, operational workbooks, and generated reports.

To run the current workflow locally, place the authorized reference files below in this directory:

- `CEDEX Master.xlsx`
- `DamageCodes.xlsx`
- `ifgEquipmentISOGroup.xlsx`

The pipeline writes generated reports to `data/output/`. Do not commit real-world input or output workbooks without written authorization.
